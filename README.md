# Signal Store WebMCP Demo

React-пример интернет-магазина, который показывает, как страница может объявлять инструменты для браузерного AI-агента через экспериментальный WebMCP API.

Демо собрано для статьи о WebMCP: обычный пользователь работает с каталогом, карточкой товара и корзиной через UI, а агент может выполнять те же сценарии через структурированные tools вместо кликов по DOM.

## Что внутри

- React + Vite SPA без бэкенда.
- Каталог из шести товаров, поиск, фильтр категории, максимальная цена и фильтр наличия.
- Карточка товара и корзина, которые обновляются из того же состояния, что и обычный UI.
- Регистрация WebMCP-инструментов через `document.modelContext.registerTool()`.
- Playwright-тесты с мок-реестром WebMCP для проверки контракта tools без экспериментального Chrome.

## WebMCP-инструменты

Страница регистрирует три инструмента:

| Инструмент | Что делает |
| --- | --- |
| `search_products` | Применяет фильтры каталога и возвращает найденные товары. |
| `show_product` | Открывает карточку товара по `productId`. |
| `add_to_cart` | Добавляет товар в корзину и показывает корзину пользователю. |

Инструмент оформления заказа намеренно не добавлен: покупка является необратимым действием и в реальном продукте должна требовать отдельной авторизации, проверки цены/остатков и явного подтверждения человека.

## Требования

- Node.js `20.19+` или `22.12+`.
- npm.
- Для реальной проверки WebMCP: Chrome с включенным экспериментом WebMCP.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite, обычно `http://localhost:5173`.

## Сборка и тесты

```bash
npm run build
npm test
```

Тесты используют Playwright и подменяют `document.modelContext`, поэтому их можно запускать в обычном окружении без Chrome Origin Trial.

## Проверка в Chrome

Обычный интерфейс работает во всех современных браузерах. Для вызова настоящих WebMCP-инструментов нужен Chrome с поддержкой эксперимента:

1. Откройте `chrome://flags/#enable-webmcp-testing`.
2. Переключите **WebMCP for testing** в состояние **Enabled**.
3. Перезапустите Chrome.
4. Установите расширение [Model Context Tool Inspector](https://chromewebstore.google.com/detail/model-context-tool-inspec/gbpdfapgefenggkahomfgkhfehlcenpd).
5. Откройте локальный сайт и проверьте список tools в Inspector.

Используйте Inspector только на доверенном локальном стенде или в отдельном профиле браузера: запросы из его чата могут отправляться внешней модели.

## Важные ограничения

WebMCP находится в экспериментальном статусе, API и требования Chrome могут меняться. Если пример перестал работать в свежем браузере, сначала проверьте актуальную документацию Chrome и черновик спецификации.
